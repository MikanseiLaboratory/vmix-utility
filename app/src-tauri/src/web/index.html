vmix-utility HTTP server

These pages are served by the vmix-utility desktop app. They are read-only: vMix state is pushed over WebSocket, control commands are never accepted from the browser.

  • Multiviewer Live tally, titles and audio meters for a vMix Multiview input. Add ?input=N to pick the input number and &host=192.0.2.10 to pick the connection.
