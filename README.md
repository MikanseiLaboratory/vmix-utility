### About / 概要

vmix-utilityは、vMix接続とオペレーションを最適化するデスクトップアプリケーションです。Tauri（Rust + React）で構築されています。

### Features / 機能

- **Shortcut Generator** - Shortcut FunctionのURLを作成生成機能
- **Blank Generator** - Blank/Colours入力を一括生成可能
- **Multiviewer** - 使用中のマルチビューに白枠や緑枠・赤枠を設定出来るWebページ
- **Video Seeker** - 特定の動画ファイルの映像をフレーム単位で送る機能
- **Input Manager** - Inputを閲覧・管理
- **List Manager** - Input Listの閲覧・管理
- **Settings** - アプリ本体の設定
- **About** - リポジトリ・ライセンス・コミュニティ（Discord等）・支援の案内など

### Installation / インストール

GitHub [Releases](https://github.com/MikanseiLaboratory/vmix-utility/releases)から最新版をダウンロードしてください。

- **Windows**: `.msi` installer
- **macOS**: `.dmg` file (Intel and Apple Silicon)
- **Linux**: `.AppImage` file
